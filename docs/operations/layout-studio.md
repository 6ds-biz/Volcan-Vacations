# Temporary Layout Studio — retired

The temporary Owner dashboard Layout Studio has been replaced by the reusable 6DS Page Builder V1 after validation of its editor, media picker, publishing, revision restore and device rendering.

Use **Edit Page** on a supported Operations page. See [the VV integration guide](../page-builder/vv-integration.md).

The former `vv-layout-studio-owner-v1` browser key is removed on Owner page entry. Temporary local drafts do not become server publications. The old Studio component, preview renderer, schema helper, tests and styles have been removed. The approved live dashboard modules remain and are supplied to the reusable renderer.
